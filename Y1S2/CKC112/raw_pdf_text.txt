Abstract Data Types
•                                                                                                 A data type that specifies
•                                                                                 values that can be stored
•                                                                                 operations that can be done on the values
•                                                                                                 User of an abstract data type does not 
need to know the implementation of the 
data type,                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                         e.g.                                                                                                                                                                                          , how the data is stored
•                                                                                                 ADTs are created by programmers

Abstraction and Data Types
•                                                                                                 Abstraction                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                              : a definition that captures general 
characteristics without details
•                                                                                 Ex: An abstract triangle is a 3-                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                               sided polygon. A specific triangle 
may be scalene, isosceles, or equilateral
•                                                                                                 Data Type                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                 defines the values that can be stored in a 
variable and the operations that can be performed on it

(1 of 2)
